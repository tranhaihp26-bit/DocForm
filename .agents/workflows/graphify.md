# Workflow: graphify

Follow the project Graphify rule and the repository `AGENTS.md` before running commands. For DocForm, use code-only AST extraction; do not run semantic extraction over documents or fixtures.

If no path argument is given, use `.` (current directory). If a code-only graph already exists, answer navigation questions from it and verify claims in current source/tests.
